## 2. 项目概述

### 2.1 产品定位
一个短链接生成与跳转服务，支持长链转短链、302 跳转、访问统计、过期失效、密码保护、恶意链接拦截、限流防刷。

### 2.2 核心价值
- 长链变短，便于分享
- 相同长链强制同码，便于管理
- 完整访问统计（PV/UV/趋势/来源/设备/地域）
- 安全可控（恶意拦截、限流、密码保护）
- 提供 Swagger 在线接口文档，便于联调

### 2.3 目标用户
- 需要分享长链接的个人/运营
- 需要统计点击数据的营销人员
- 需要 API 集成的开发者

## 3. 技术栈与部署

### 3.1 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vue 3 + Vite + Pinia + Vue Router + Axios + ECharts |
| 后端 | Flask + SQLAlchemy + Flask-Migrate + Marshmallow |
| 接口文档 | Swagger |
| 数据库 | MySQL 5.7 |
| 缓存/限流 | Redis 7 |
| Web 服务器 | Nginx |
| 容器 | Docker + Docker Compose |

**MySQL 5.7 使用约束（重要）**
- 字符集统一使用 utf8mb4，排序规则 utf8mb4_unicode_ci
- 存储引擎统一使用 InnoDB
- 不支持窗口函数、部分 JSON 高级函数（8.0 才有）
- 不支持 CHECK 约束（写了不生效，需业务层校验）
- 单列索引前缀默认 767 字节，长 URL 无法直接建唯一索引，必须存储 URL 哈希值列来建索引
- 时间类型统一用 DATETIME，避免 TIMESTAMP 的 2038 问题
- TEXT 类型不能直接建唯一索引

### 3.2 部署架构

用户访问后，由 Nginx 统一入口分流：
- 前端静态资源（Vue 构建产物）
- 接口请求转发到 Flask 后端
- 接口文档路径转发到 Swagger
- 短码跳转路径转发到 Flask 后端

后端连接 MySQL 5.7 与 Redis。短链以域名形式返回，不支持自定义域名。Nginx 负责透传真实 IP，供限流与 UV 统计使用。

#### F1.1 长链转短链

**功能描述**  
用户提交长链接，系统返回唯一短链。相同长链强制返回相同短码。

**输入**
- 长链接（必填）：原始链接
- 过期时间（选填）：不填则使用默认有效期

**输出**
- 短码
- 完整短链
- 原始长链
- 创建时间
- 过期时间

**业务规则**
1. 短码长度 6~8 位，由字母和数字组成
2. 相同长链强制返回相同短码
3. 长链需为合法 http/https 链接
4. 长链长度上限可配置，默认 2048 字符
5. 生成前需经过恶意链接拦截
6. 不提供自定义短码

**异常处理**

| 场景 | 提示 | HTTP |
|------|------|------|
| 空或非法链接 | 链接格式不正确 | 400 |
| 超长链接 | 链接超出长度限制 | 400 |
| 恶意链接 | 链接被拦截 | 400 |
| 触发限流 | 请求过于频繁 | 429 |

**验收标准**
- 合法长链能生成短链
- 相同长链返回同一短码
- 非法或恶意输入被拒绝
- 并发生成不产生重复

---

#### F1.2 短码跳转

**功能描述**  
用户访问短链，系统 302 重定向到原始长链。

**输入**：短码

**输出**：302 重定向到原始长链

**业务规则**
1. 使用 302 临时重定向，保证统计可追踪
2. 命中后访问次数加一，作为 PV
3. 异步记录点击日志，包含 IP，供 UV 计算
4. 惰性判断是否过期
5. 已软删、停用、标记恶意的短链不跳转

**异常处理**

| 场景 | HTTP |
|------|------|
| 短码不存在 | 404 |
| 短链已过期 | 410 |
| 短链已软删或停用 | 410 |
| 短链被标记恶意 | 403 |
| 密码未验证 | 401，展示密码页 |

**验收标准**
- 有效短码正确 302 跳转
- 跳转后 PV 加一，写入日志
- 过期、删除、停用、恶意返回对应状态码

---

#### F1.3 访问统计

**功能描述**  
查询短链统计信息，字段尽量全。

**输入**：短码

**输出字段**

| 字段 | 说明 |
|------|------|
| 短码 | 短码 |
| 原始长链 | 原始长链 |
| 完整短链 | 完整短链 |
| PV | 总点击次数 |
| UV | 去重 IP 数 |
| 创建时间 | 创建时间 |
| 过期时间 | 过期时间 |
| 状态 | 启用、过期、停用、已删、恶意 |
| 是否密码保护 | 是否启用密码 |
| 最近访问时间 | 最近一次访问时间 |

**业务规则**
1. PV 来自访问次数字段的原子自增
2. UV 来自点击日志按 IP 去重
3. 不存在的短码返回 404

**验收标准**
- PV 随跳转准确增长
- UV 不大于 PV
- 并发下计数不丢失

---

#### F1.4 链接管理

**功能描述**  
用户对名下短链进行查询、删除、恢复、启停。

| 操作 | 说明 |
|------|------|
| 列表 | 分页查询我的短链，默认过滤已删；`only_deleted=1` 切到回收站视图 |
| 详情 | 查看单条 |
| 删除 | 软删除，短码不复用，可从回收站恢复 |
| 恢复 | 撤销软删，短码、统计、风控规则原样还原 |
| 启用/停用 | 停用后不跳转 |

**业务规则**
1. 仅能操作自己名下链接，需鉴权
2. 软删保留统计数据
3. 软删后短码不复用
4. 软删可逆：恢复时由 `url_hash(long_url, domain, channel)` 重算原始哈希写回。
   该函数是纯函数且三个字段创建后不可改，因此可精确还原。
5. 恢复冲突：软删期间若同一条长链已被重新生成，活跃记录会占用同一哈希，
   此时拒绝恢复并返回 409，提示用户改用新短码（不做合并）。

**验收标准**
- 列表分页正确
- 删除后跳转返回 404（不暴露"该短码曾存在"），回收站可见
- 恢复后跳转恢复 302，`url_hash` 与删除前完全一致
- 反复删除/恢复哈希无损；同链已重新生成时恢复返回 409
- 停用后跳转返回 410

#### F3.3 密码保护

**规则**

**验收标准**
- 无密码无法跳转，返回 401
- 正确密码可跳转
- 2 小时内免重复输入
- 多次错误触发限制

**验收标准**

**规则**

2. 生成时校验，跳转前二次校验

   - 域名黑名单
   - 关键词或正则规则
4. 安全库不可用时降级，由参数控制：
   - 放行或拒绝
   - 校验总开关

**异常**

| 场景 | HTTP |
|------|------|
| 生成恶意链接 | 400 |
| 访问已标记恶意 | 403 |

**验收标准**
- 黑名单样本被拦截
- 降级参数生效

**规则**

**验收标准**

**验收标准**

## 6. 短码生成算法设计

### 6.1 设计目标
零碰撞、空间充分利用、防枚举、并发安全、长度 6~8 位。

### 6.2 算法流程

生成过程分三步：
1. 从数据库获取唯一自增 ID
2. 通过仿射变换对 ID 打散，防止短码连续可枚举
3. 对打散后的数字进行 Base62 编码，得到短码

### 6.3 仿射变换

使用一个线性同余映射，将 ID 映射到短码空间。
- 映射必须是双射，保证不碰撞
- 参数中乘数需与空间大小互质
- 映射可逆，便于从短码反推 ID

### 6.4 Base62 编码

使用 62 个字符（数字 0-9、大写字母 A-Z、小写字母 a-z）表示数字。
- 字符顺序固定
- 不足最小长度时前补 0

### 6.5 长度策略

- 默认 6 位起步
- 当 ID 超出 6 位容量后自动升为 7 位
- 容量参考：6 位约 568 亿，7 位约 3.5 万亿，8 位约 218 万亿

### 6.6 边界处理

| 场景 | 处理 |
|------|------|
| ID 超出 6 位容量 | 自动升 7 位 |
| 分布式 ID | 使用号段或雪花算法 |
| 打散方式 | 必须双射，禁用哈希 |
| 前导 0 | 补 0 到固定长度 |
| 软删短码 | 不复用 |
| 仿射参数 | 乘数需与空间大小互质，需校验 |

### 6.7 生成流程

1. 校验长链合法性，非法返回 400
2. 恶意链接拦截，命中返回 400
3. 计算长链哈希值
4. 查询哈希是否已存在，存在直接返回已有短码
5. 不存在则：
   - 获取自增 ID
   - 仿射变换打散
   - Base62 编码得到短码
   - 入库，唯一索引兜底并发
6. 返回完整短链

**并发兜底**：唯一索引冲突时捕获异常，回查并返回已有短码。

### 6.8 为什么不用随机生成

随机生成加查重在数据量增大后碰撞率快速上升，重试成本高，且空间利用率低。自增 ID 加打散方案零碰撞、空间满用、防枚举。

## 7. 数据库设计

### 7.1 MySQL 5.7 约束说明

| 约束 | 说明 |
|------|------|
| 字符集 | utf8mb4 / utf8mb4_unicode_ci |

- 创建时间

**点击日志表**
- 主键：自增 ID
- 短码
- 访问者 IP
- User-Agent
- Referer
- 点击时间

**用户表**

## 8. 接口设计（API）

### 8.1 通用约定
- 接口前缀统一
- 请求与响应均为 JSON
- 时间使用 ISO 8601 UTC
- 鉴权支持 Cookie 会话或 Bearer Token

### 8.3 接口说明

**生成短链**
- 输入：长链接、可选过期时间
- 输出：短码、完整短链、原始长链、创建时间、过期时间
- 错误：400、429

**短码跳转**
- 输入：短码
- 输出：302 重定向
- 错误：401、403、404、410

**访问统计**
- 输入：短码
- 输出：短码、原始长链、完整短链、PV、UV、创建时间、过期时间、状态、是否密码保护、最近访问时间
- 错误：404

**我的链接列表**
- 输入：页码、每页数量、是否含已删、是否只看已删（回收站）
- 输出：总数、页码、每页数量、列表项（含 `is_deleted`、`deleted_at`）

**删除链接**
- 输入：短码
- 输出：删除结果
- 行为：软删除，进入回收站

**恢复链接**
- 输入：短码
- 输出：恢复后的链接详情
- 行为：撤销软删，重算并写回原始 `url_hash`
- 错误：404（不存在 / 越权）、409（同链已重新生成新短码）

**修改链接**
- 输入：短码、新状态
- 输出：短码、新状态

**注册**
- 输入：用户名、密码
- 输出：用户 ID、用户名、API Key

**登录**
- 输入：用户名、密码
- 输出：用户 ID、用户名、Token

**密码验证**
- 输入：短码、密码
- 输出：验证结果，并下发有效期为 2 小时的凭证

**健康检查**
- 输出：服务、数据库、Redis 状态

### 8.4 统一错误响应

错误响应包含错误码与错误信息，便于前端处理与提示。

## 13. 边界情况汇总

| 场景 | 处理 |
|------|------|
| 非法链接 | 400 |
| 超长链接 | 400 |
| 恶意链接 | 400 |
| 短码不存在 | 404 |
| 短码过期 | 410 |
| 短码软删 | 410 |
| 短码停用 | 410 |
| 短码恶意 | 403 |
| 密码未验证 | 401 |
| 限流 | 429 |
| 并发插入同长链 | 唯一索引兜底加回查 |
| 哈希碰撞 | SHA256 可忽略，回查比对 |
| 短码空间 | 自增 ID 加 Base62，零碰撞 |
| ID 超出 6 位容量 | 升 7 位 |
| 软删短码 | 不复用 |
| 仿射参数 | 乘数需与空间大小互质，需校验 |
| 真实 IP | Nginx 透传 |

## 14. 验收标准

### 模块一
- 合法长链生成短链
- 相同长链返回同一短码
- 并发生成无重复
- 有效短码正确 302
- 跳转后 PV 加一，写入日志
- PV 随跳转准确增长
- UV 不大于 PV
- 列表分页正确
- 删除后跳转返回 404，停用后返回 410
- 软删可从回收站恢复，恢复后跳转恢复 302

### 模块二
- 趋势数据一致
- 来源分类准确
- 地域数据可展示
- 设备分类可展示
- 同窗口同 IP 计为 1
- 导出内容正确

### 模块三
- 到期后无法跳转
- 达到点击上限停止
- 无密码无法跳转
- 2 小时内免输入
- 黑名单被拦截
- 降级参数生效
- 超频被限流
- 刷量被识别

### 算法
- 连续 ID 短码不连续
- 短码可逆解回 ID
- 短码仅含字母和数字
- 6 位起步，超出升位

### 接口文档
- 文档首页可访问
- 规范文件合法
- 接口说明完整
- 可在线调试
